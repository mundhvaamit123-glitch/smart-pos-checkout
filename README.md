# Autonomous Unmanned Smart POS Retail SaaS Solution


This is a highly innovative cloud-based SaaS software that connects with hardware sensors to enable 100% unmanned bulk retail checkouts. No staff or cashier needed.
  
   ## Key Features:
- *Bulk Conveyor Intake:* Drops a full bag onto an automated rolling conveyor belt.
- *Instant RFID Counting & Weight Detection:* Counts items and calculates total price instantly.
- *Secure Mobile QR Payment:* Generates a dynamic QR code for secure digital checkout.
- *Smart Exit Gates & Fraud Alarm:* Automated security glass gates open after verification. Includes active anti-theft sensors.
- *UV-C Sanitization System:* Automatically sterilizes the belt area between customers.
